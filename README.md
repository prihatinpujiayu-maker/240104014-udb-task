tugas manajement jaringan

## Cara Menjalankan

1. Pastikan Docker sudah aktif.
2. Buka terminal di folder project ini.
3. Jalankan perintah: docker compose up -d

4. Akses phpMyAdmin di browser:
   - http://localhost:8080

Login menggunakan:
- User: root 
- Password: (sesuai yang diatur di docker-compose.yml)
